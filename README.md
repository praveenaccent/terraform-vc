# Version Control Infrastructure
 
## Project Goal
Track Terraform infrastructure updates using Git and GitHub.
 
## Tools Used
- Linux
- Git
- GitHub
- Terraform
 
## Implementation
1. Created Terraform configuration.
2. Initialized a Git repository.
3. Committed infrastructure code.
4. Pushed code to GitHub.
5. Created a feature branch.
6. Submitted a Pull Request.
 
## Validation
Terraform configuration is validated locally.
